API Reference

ScribeAI provides a single REST API for generating high-quality content using the best language models available. All requests are authenticated via API key and return structured JSON.

Base URL https://api.scribeai.dev/v1
ℹ️ All requests must be sent over HTTPS. The API uses standard HTTP response codes. Dates and times are in UTC ISO 8601 format.

Authentication

ScribeAI uses API key authentication. Include your key in the Authorization header on every request.

# Include in every request
Authorization: Bearer sk_live_your_api_key_here

Your API key is available in your dashboard. Keys follow the format sk_live_xxxx. Keep your key secret — never expose it in client-side code.

⚠️ If you suspect your key has been compromised, regenerate it immediately from the dashboard. Old keys are invalidated instantly on regeneration.

Errors & Rate Limits

ScribeAI uses standard HTTP response codes. Errors return a JSON body with a code and human-readable message.

200Success. Generation completed.
400Bad request. Missing or invalid parameters. Check the message field.
401Unauthorized. Invalid or missing API key.
429Token quota exceeded. Upgrade your plan or wait for reset.
500Server error. Upstream model unavailable. Retry after 5s.
// Example error response
{
  "error": {
    "code": "quota_exceeded",
    "message": "Monthly token quota exceeded. Resets in 14 days.",
    "tokens_used": 500000,
    "tokens_limit": 500000
  }
}

Rate limits are per-API-key: 60 requests/minute on all plans. Streaming requests count as a single request.

Generate Content

POST /v1/generate Create a new generation

The primary endpoint. Submits a generation request and returns the completed content synchronously. For long-form content, consider using the streaming endpoint.

Request Parameters

ParameterTypeRequiredDescription
typestringrequiredContent type. See Content Types for full list.
topicstringrequiredThe topic, prompt, or subject to generate content about. Max 500 chars.
tonestringoptionalWriting tone. Options: professional, casual, persuasive, witty. Default: professional.
wordsintegeroptionalTarget word count. Range: 50–2000. Default varies by content type.
modelstringoptionalOverride model selection. Options: gpt-4o, gpt-4o-mini, claude-sonnet. Pro+ plans only.
languagestringoptionalOutput language code (ISO 639-1). Default: en. Supports 40+ languages.
 
$ curl -X POST https://api.scribeai.dev/v1/generate \
  -H "Authorization: Bearer sk_live_xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "blog_intro",
    "topic": "The future of remote work in 2025",
    "tone": "professional",
    "words": 200
  }'

Stream Content

POST /v1/generate Add "stream": true to any generate request

Add "stream": true to any generate request to receive a Server-Sent Events (SSE) stream. Tokens are delivered as they are generated. Available on Pro and Scale plans.

// Stream request — same endpoint, add stream: true
{
  "type": "blog_intro",
  "topic": "AI in healthcare",
  "stream": true
}

// SSE response stream
data: {"delta": "Healthcare"}
data: {"delta": " is experiencing"}
data: {"delta": " its most significant"}
data: {"delta": " transformation in decades..."}
data: {"done": true, "tokens_used": 214, "id": "gen_01jk..."}

List History

GET /v1/generations List past generations

Returns a paginated list of your past generations, newest first. Supports filtering by content type.

Query ParamTypeRequiredDescription
limitintegeroptionalNumber of results. Default 20, max 100.
offsetintegeroptionalPagination offset. Default 0.
typestringoptionalFilter by content type (e.g. blog_intro).
 
GET /v1/generations?limit=10&type=blog_intro

{

  ],
  "total": 1247,
  "offset": 0,
  "limit": 10
