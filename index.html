// how it works

Built for developers.
Ready in minutes.

One API key. One endpoint. Every content type. ScribeAI handles model routing, prompt engineering, and output formatting for you.

01
🔑

Register & get your key

Sign up with email. Your API key is generated instantly — format: sk_live_xxxx. Free tier starts immediately.

02
📡

POST to /v1/generate

Send your content type, topic, tone, and word count. ScribeAI picks the best model and crafts the optimal prompt behind the scenes.

03
⚡

Get content back in <400ms

Receive structured JSON with your content, word count, tokens used, and the model that generated it. Stream support available.

04
📊

Monitor in dashboard

Track generations, token usage, history, and billing — all in your real-time dashboard. Upgrade your plan when you need more.

// features

Everything you need.
Nothing you don't.

✍️

15+ Content Types

Blog intros, full articles, ad copy, email subjects, product descriptions, social posts, SEO meta tags, and more — all from one endpoint.

🤖

Multi-Model Routing

ScribeAI automatically routes requests to GPT-4o, Claude Sonnet, or Llama based on content type and performance benchmarks.

🔒

JWT Auth + RLS

All API keys are tied to authenticated users via Supabase Auth. Row Level Security enforces data isolation at the database layer.

📈

Token-Based Quotas

Usage is metered per token. Every plan has a monthly token limit. Overage is blocked gracefully — no surprise charges.

🌊

Streaming Support

Add "stream": true to any request and receive SSE tokens in real time — perfect for building live typing UIs.

📜

Generation History

Every generation is logged. Browse, search, and re-download any past output from your dashboard. 90-day retention on all plans.
